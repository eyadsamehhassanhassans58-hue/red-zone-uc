RED ZONE UC — ملفات المتجر

الملفات:
- app.py: الموقع ولوحة الإدارة.
- requirements.txt: المكتبات اللازمة.
- render.yaml: إعدادات خدمة Render.

مهم قبل النشر:
1) ارفع الملفات إلى مستودع GitHub.
2) في Render اختر New > Web Service واربط المستودع.
3) أضف متغير البيئة ADMIN_PASSWORD_HASH. لإنشاء تجزئة لكلمة السر، شغّل محليًا:
   python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('ضع_كلمة_سر_قوية_هنا'))"
   ضع الناتج في ADMIN_PASSWORD_HASH، ولا تضع كلمة السر الأصلية نفسها.
4) افتح /admin/login لتسجيل الدخول.
5) تأكد من إعداد تخزين دائم (Persistent Disk) لـ SQLite على Render، وإلا قد تضيع الطلبات عند إعادة النشر أو إعادة التشغيل. اضبط DB_PATH على مسار داخل القرص الدائم إذا أضفته.
6) لا تؤكد الدفع إلا بعد التحقق الفعلي من وصول المبلغ.

ملاحظة: الملفات لا تنشر الموقع تلقائيًا ولا تنشئ رابطًا عامًا بنفسها. لا تشارك كلمة السر أو متغيرات البيئة.
